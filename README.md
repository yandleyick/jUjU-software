# Julian & Walter’s workspace

Use this repository for the projects we work on together. Keep each project in its own folder so both of us can work on different things at once.

## Starting something new

Create `projects/<project-name>/README.md`. Write down what we want to make, where the source files live, and the next step. For a large recording, video, or design file, link to the shared original in the project notes.

## Picking up work

Use a chat in our shared ChatGPT Project for each topic. When a decision changes what we’re building, add it to the relevant project’s README so either of us can pick it up in Codex. For code changes, start a branch and open a pull request. Include what changed, how you checked it, and anything the other person needs to do next.
